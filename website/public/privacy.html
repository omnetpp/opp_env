Privacy policy

opp_env download statistics · last updated 27 November 2026

opp_env reports which OMNeT++ releases and simulation models it downloads, so that the OMNeT++ project can see how they are used. This page describes what is recorded, why, and how to opt out.

How it works

opp_env downloads archives and repositories directly from their original location (usually GitHub), under that site's own privacy policy. After a project has been downloaded successfully, opp_env sends a short report to https://oppenv.omnetpp.org/report. The report contains no URL, only the data listed below. Nothing is sent when installing from local copies (--local).

What is recorded

For each downloaded project, one record with:

  • the date (UTC, without the time of day);
  • the country the report came from, as determined by Cloudflare from the IP address at the time of the request;
  • sent by opp_env: the project name and version, whether it was installed as a dependency of another project, the host operating system (Linux, macOS or WSL), the CPU architecture, the opp_env version, and whether it runs in a CI system (the CI environment variable is set).

What is not recorded

IP addresses, user or host names, file paths, download URLs, cookies, or any other identifier are not stored, and neither is the time of day, so a record cannot be traced back to a person or a machine. Downloads reported together (for example a model and the OMNeT++ release it needs) share their date, country and platform, but so do downloads by different users on the same day.

Why

To learn which OMNeT++ versions and models are actually used, on which platforms, and in which regions. This helps decide which versions and platforms to keep supporting and testing, and shows model authors how their work is used.

Infrastructure

The reports are received by a Cloudflare Worker and stored in Cloudflare D1. Cloudflare necessarily processes each request, including its IP address, to deliver it; see the Cloudflare privacy policy. To prevent abuse, Cloudflare counts the reports from each IP address for one minute; these counters are not stored with the statistics. The service does not keep request logs of its own.

How long records are kept

Indefinitely. Since the records contain no personal data, they are kept to show long-term trends.

Opting out

Set the OPP_ENV_NO_TELEMETRY or DO_NOT_TRACK environment variable to any non-empty value:

export OPP_ENV_NO_TELEMETRY=1

opp_env then sends no reports at all. Downloads work the same either way.

Questions

Open an issue in the opp_env issue tracker.
